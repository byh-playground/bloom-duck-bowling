# 구조와 상태 소유권

| 원본                            | 책임                                                                                |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| `index.html`, `styles/game.css` | 브라우저 엔트리, HUD·입력 컨트롤 레이아웃                                           |
| `src/app/`                      | 입력·게임·렌더를 조립하고 화면과 메뉴를 갱신. 기록을 저장하는 브라우저 경계         |
| `src/input/`                    | 포인터·키보드 입력을 대시 방향 및 투구 명령으로 변환                                |
| `src/domain/`                   | 물리, 상태 전이, 맵, 웨이브, 증강, 점수를 소유. DOM·브라우저 저장소에 접근하지 않음 |
| `src/presentation/`             | 카메라·스케치풍 Canvas 2D·투구 패드 표시. 물리 상태와 판정은 수정하지 않음          |

`CampaignGame`은 한 판, `BowlingGame`은 그 바탕인 공·핀의 물리 시뮬레이션을 담당합니다. 현재 방과 방문 상태는 `expedition.mjs`가 만들고 전이시킵니다. 맵 이름·해금 키·방 크기·분기 구역·핀 배치/치환의 원본은 `arena.mjs`입니다. 새 맵은 게임 진행·메뉴 곳곳에 맵 ID 조건을 추가하기 전에 기존 맵 데이터로 표현할 수 있는지 먼저 봅니다. 화면의 팔레트와 장식은 표시 계층이 소유합니다.

`timing.mjs`의 한 틱 속도에서 입력/시뮬레이션과 물리/투구 예측 간격이 함께 파생됩니다. 기존 연속 물리는 초 단위 계산을 유지하고, 이미 정수 밀리초인 전투 경고·피해 타임라인은 `combat-clock.mjs`에 남습니다. 이관에서 기존 게임의 확정된 속도나 시간은 바꾸지 않습니다.

`localStorage` 스키마와 키를 그대로 유지합니다. 저장은 한 판 결과가 기록될 때만 일어나고, 게임 호스트가 바뀌면 브라우저의 출처 격리로 저장이 공유되지 않습니다.

## 메뉴 흐름

홈과 맵 선택에서는 경기 객체를 생성하지 않습니다. `app.mjs`가 카드 선택 때 경기 생성과 실행을 시작하며, `front-menu.mjs`가 해금 상태를 읽어 두 맵 카드의 접근 가능 여부를 표시합니다. 설정은 홈이나 일시정지를 호출 부모로 유지합니다. 새 폭풍 길 해금은 처음 기록된 숲길 5구역 도달 결과에 표시됩니다. 진행 중인 폭풍 길에서 기록을 초기화했다면 그 판은 계속할 수 있지만, 이전 도전을 기록해 해금을 바로 복구하거나 잠긴 맵을 다시 시작하지 않습니다.
