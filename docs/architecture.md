# 구조와 상태 소유권

| 원본                            | 책임                                                                                |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| `index.html`, `styles/game.css` | 브라우저 엔트리, HUD·입력 컨트롤 레이아웃                                           |
| `src/app/`                      | 입력·게임·렌더를 조립하고 화면과 메뉴를 갱신. 기록을 저장하는 브라우저 경계         |
| `src/input/`                    | 포인터·키보드 입력을 대시 방향 및 투구 명령으로 변환                                |
| `src/domain/`                   | 물리, 상태 전이, 맵, 웨이브, 증강, 점수를 소유. DOM·브라우저 저장소에 접근하지 않음 |
| `src/presentation/`             | 카메라·스케치풍 Canvas 2D·투구 패드·사운드를 표현. 물리 상태와 판정은 수정하지 않음 |

`CampaignGame`은 한 판, `BowlingGame`은 그 바탕인 공·핀의 물리 시뮬레이션을 담당합니다. 현재 방과 방문 상태는 `expedition.mjs`가 만들고 전이시킵니다. 맵·플레이어 캐릭터 정의는 각각의 콘텐츠 파일에서 읽습니다. 시뮬레이션은 물리와 규칙을, 렌더러는 실제 그리기를 소유합니다.

GameKit `simloop`가 고정 틱 일정, 프레임 호출, 일시정지 뒤 누적 시간 초기화를 맡습니다. `timing.mjs`의 한 틱 속도에서 입력/시뮬레이션과 물리/투구 예측 간격이 함께 파생됩니다. 기존 연속 물리는 초 단위 계산을 유지하고, 이미 정수 밀리초인 전투 경고·피해 타임라인은 `combat-clock.mjs`에 남습니다. 이관에서 기존 게임의 확정된 속도나 시간은 바꾸지 않습니다.

`localStorage` 스키마와 키를 그대로 유지합니다. 저장은 한 판 결과가 기록될 때만 일어나고, 게임 호스트가 바뀌면 브라우저의 출처 격리로 저장이 공유되지 않습니다.

## 콘텐츠 정의

- 맵은 `src/content/maps/<id>.mjs`에 기본 export 객체 하나를 둡니다. 이름·카드·해금 문구, 경기장 경계와 시작 위치, 구역별 등장 패킷, 핀 줄 기준점과 치환을 같은 파일에 적습니다. `grove.mjs`과 `storm.mjs`가 두 지형의 예입니다. 카드에는 기존 이미지 주소나 정의에 담은 SVG 데이터 URL을 쓸 수 있습니다. `unlockAt`은 기존 기록의 최고 도달 구역을 기준으로 하고, 생략한 맵은 처음부터 열립니다.
- 플레이어 캐릭터는 `src/content/bowlers/<id>.mjs`에 기본 export 객체 하나를 둡니다. 이름, 충돌 반경, 색을 정의합니다. 생략한 반경과 색은 기본 오리의 값을 사용합니다. 캐릭터가 둘 이상이면 맵 선택에서 고를 수 있습니다. 형태가 다른 캐릭터는 같은 정의에 `draw({ context, pose, palette, project, point, radius, flashing, drawHeldBall })`를 넣을 수 있습니다. `point(side, forward, height)`는 기존 방향과 피격 기울기를 적용한 월드 좌표를 반환하고, `project(point)`는 이를 화면 좌표로 투영합니다. 공을 들고 있을 때만 `drawHeldBall()`이 제공됩니다. 새 이동이나 투구 규칙은 별도 동작으로 구현합니다.
- 파일을 더하거나 지운 뒤 `npm run content:index`를 실행하면 `src/content/index.mjs`의 브라우저용 정적 import 목록이 갱신됩니다. 목록도 함께 커밋합니다. 기존 메뉴나 게임 루프는 같은 목록을 읽으며, 로딩과 배포는 기존 브라우저 ES 모듈을 그대로 사용합니다.
- 개별 맵이나 캐릭터의 이름으로 분기하며 기능을 추가할 필요가 있으면 그 기능의 공통 동작을 먼저 정의합니다. 예를 들어 완전히 새로운 지형 모델에는 그 지형의 표시와 판정이 필요합니다. 쇼케이스의 장면 선택은 콘텐츠 등록과 별도로 관리합니다.

## 지형

반사 바위는 맵 정의의 `trail[].reflectors`에 둡니다. `positions`에는 구역 왼쪽 위를 기준으로 한 중심 좌표 후보 `{ x, y }`를 넣고, `length`·`width`·`angleRad`·`height`로 모양을 지정합니다. 판정과 렌더러는 같은 사각형을 읽습니다. 공과 조준 예측은 `stepRoll`의 같은 반사 판정을 공유합니다. 공을 처음 반사시킨 순간 바위가 깨지고, 시뮬레이션 시간이 `respawnMs`만큼 지나면, 직전 위치와 오리·핀·공이 겹치는 후보를 제외해 다시 나타납니다. 빈 후보가 없으면 기다립니다. 첫 위치와 재등장은 판마다 받은 시드에서 지형 전용 난수 순서로 고릅니다. 오리와 핀은 나타나 있는 동안 바위 옆면에 막혀 미끄러지고, 바위보다 높은 몸체는 넘을 수 있습니다. 조준선은 현재 보이는 바위로 궤적을 그리고, 예측에서 한 번 맞힌 바위는 이후 경로에서 제외합니다.

## 초기 로딩

`src/app/main.mjs`가 GameKit `boot`로 게임 모듈, 홈 이미지 디코딩, 초기 배경음 준비의 완료를 보고합니다. 필수 파일을 읽거나 초기화하지 못하면 로딩 화면에서 다시 불러올 수 있습니다. 배경음 오류는 로그에 남기고 홈으로 이동합니다. 홈에서는 첫 입력부터 오디오를 재생합니다.

게임 버전은 `index.html`의 `#product-version` 한 곳에 SemVer로 둡니다. 같은 요소가 로딩에서 홈으로 이동합니다. 빌드 출처는 Git 커밋과 Nightly 태그가 나타냅니다.

## 메뉴 흐름

홈과 맵 선택에서는 경기 객체를 생성하지 않습니다. `app.mjs`가 카드 선택 때 경기 생성과 실행을 시작하며, `front-menu.mjs`가 각 맵 정의와 해금 상태를 읽어 카드의 접근 가능 여부를 표시합니다. 설정은 홈이나 일시정지를 호출 부모로 유지합니다. 새 폭풍 길 해금은 처음 기록된 숲길 5구역 도달 결과에 표시됩니다. 진행 중인 폭풍 길에서 기록을 초기화했다면 그 판은 계속할 수 있지만, 이전 도전을 기록해 해금을 바로 복구하거나 잠긴 맵을 다시 시작하지 않습니다.

홈·맵 선택·설정·결과는 경기 HUD의 배경·버튼·텍스트 색을 `styles/game.css`의 `--duck-*` 변수로 공유합니다. 화면별 배치는 `styles/front-menu.css`에 둡니다. 홈의 대체 정지 그림은 SVG의 코트·핀과 기존 경기 렌더러의 오리·공을 함께 씁니다. 홈 포즈는 고정되어 있고, 홈 그림을 그릴 때 경기 카메라 상태를 수정하지 않습니다.

홈은 상단을 가득 채운 시연 위에 제목을 두고, 시작·소개·설정과 버전은 아래에 배치합니다. 홈의 반복 시연은 `home-showcase.mjs`의 GameKit `createScenario`가 별도의 경기와 기존 Canvas 렌더러로 실행합니다. 각 장면은 3초이며 같은 시드로 세 장면을 반복합니다. `home-motion.mjs`는 홈에서 떠날 때 시연을 정리하고, 설정·전체 화면 소개·숨긴 탭에서는 멈춥니다. 동작 줄이기가 켜져 있거나 시연 모듈을 읽지 못한 경우에는 홈의 정지 그림을 표시합니다.

## 플레이 소개

`src/app/showcase.mjs`가 GameKit `scenario.installShowcase`의 전체 화면, 재생 제어와 `#/showcase` 주소를 연결합니다. `showcase-program.mjs`의 장면 명령은 일회용 iframe의 실제 경기 인스턴스에 적용됩니다. GameKit 시간표가 iframe의 고정 틱을 진행하므로 일시정지 때 경기까지 멈추고, 다시 보기는 새 iframe과 같은 시드에서 시작합니다.

`?showcaseDemo=1`은 영구 저장소를 초기화하지 않고 배경음도 불러오지 않습니다. 폭풍 길은 소개에서만 열립니다. 소개 중에는 본게임의 경기 틱과 소리를 멈추고, 닫으면 이전 음소거 설정과 화면으로 돌아갑니다.

## 사운드

시뮬레이션이 실제 대시 시작, 공이 손을 떠난 순간, 핀 타격·연쇄·방어, 공 회수, 오리 피격, 구역 정리를 알립니다. `app.mjs`가 이 사건을 `presentation/audio.mjs`에 넘기고, GameKit `AudioPlayer`가 효과음 재생·중복 제한·동시 소리 수·음소거를 관리합니다. 배경음은 같은 플레이어에서 루프하며 홈·경기·일시정지에 따라 음량이 바뀝니다. 소리 설정은 현재 탭에 적용됩니다.
