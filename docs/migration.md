## 수용 기준

1. 같은 시드와 조작으로 숲길 또는 폭풍 길을 시작하면 핀을 정리하기 전에는 다음 길이 열리지 않는다.
2. 증강을 고르고 입구를 넘으면 선택한 길만 이어지며 체력·공·증강이 유지된다. 같은 조건으로 두 맵 모두 5구역을 완주할 수 있다.
3. 독립 루트로 열어도 메뉴와 투구·대시 입력, 원본 자원 로딩이 동작한다. 다른 실험이나 기존 Site에 의존하지 않는다.

## 확인한 범위와 인계

Node에서 이관 전 볼링 회귀 250개를 동일한 소스 경로에 대응시켜 실행하고, 고정 시드 42·60 Hz의 두 맵 진행 중 화면 명령과 종료 상태를 기준본과 비교했습니다. 브라우저에서 원본 진입, 맵 전환, 키보드 대시·투구를 확인했습니다. 실제 휴대폰 시험, 성능 측정, 새 사이트 배포 및 Stable 승격은 이 작업에서 하지 않았습니다.

별도 게임 기능은 추가하지 않았습니다. 기존 입력·판정·호환성을 유지하기 위해 GameKit으로 물리·시계 구현체를 교체하지 않았습니다. 공통 모듈 후보는 GameKit의 `deterministic/tickTime`, `debug-tools`, `scenario`를 확인했습니다. 이후 시계/물리 계층을 바꾸는 작업이라면 동일 장면 비교를 유지한 채 별도 범위에서 평가합니다.

공개 원격 저장소는 `byh-playground/bloom-duck-bowling`입니다. 이관 시 원격 CI를 확인합니다. 기존 Site의 접근 권한과 배포는 별도이며 이 작업에서 변경하지 않습니다.
