# 덕 볼링 (Duck Bowling)

오리로 대시하고, 공을 굴려 몰려오는 핀을 쓰러뜨리는 브라우저 게임입니다.

## 실행

Node.js 22 이상에서 다음 명령을 실행하고 터미널에 표시된 주소를 엽니다.

```sh
npm run dev
```

실행 전에 패키지를 설치할 필요가 없습니다. 브라우저가 저장소 루트의 `index.html`, `src/`, `styles/`를 그대로 읽습니다. 별도 번들, 런타임 패키지, 백엔드가 없습니다. ES 모듈이므로 파일을 더블클릭하는 대신 HTTP 서버로 여세요.

- **이동:** 화면 왼쪽 방향 패드 또는 WASD. 입력을 누르고 있으면 준비된 대시가 이어집니다.
- **투구:** 오른쪽 패드에서 밀고 놓습니다. 끝을 휘면 훅. 키보드는 투구 영역을 선택하고 방향키로 각도·힘을 조정한 뒤 Space 또는 Enter를 누릅니다.
- **진행:** 구역을 정리하고 증강을 고른 다음 열린 입구를 넘습니다. 숲길에서 5구역에 도달하면 폭풍 길을 고를 수 있습니다.
- **저장:** 브라우저의 같은 출처에서 기록과 해금이 남습니다. 다른 호스트의 기록은 자동으로 옮겨지지 않습니다.

## 개발

로컬에서 추가 확인이 필요할 때는 아래 명령을 실행합니다.

```sh
npm ci
npm run check
npm test
```

`npm run check`는 포맷·린트, `npm test`는 숲길·폭풍 길 완주 시나리오를 로컬에서 실행합니다. PR CI는 변경된 JavaScript(`.js`, `.mjs`, `.cjs`)의 문법만 확인하고, 패키지 설치·포맷·린트·테스트는 실행하지 않습니다. 책임 배치는 [구조 문서](docs/architecture.md), Build 57 출처와 검증 범위는 [이관 기록](docs/migration.md), 공통 규칙 링크는 [작업 안내](AGENTS.md)에 있습니다.

## 배포

정적 게임 원본만 서비스하면 됩니다. 현재 저장소에는 공개 Pages 자동 배포가 없습니다. 기존 플레이 사이트는 이관과 별도이며, Nightly 태그는 공개 배포나 Stable 승격을 뜻하지 않습니다.
