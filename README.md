# 덕 볼링 (Duck Bowling)

오리로 대시하고, 공을 굴려 몰려오는 핀을 쓰러뜨리는 브라우저 게임입니다.

## 실행

Node.js 22 이상에서 다음 명령을 실행하고 터미널에 표시된 주소를 엽니다.

```sh
npm run dev
```

실행 전에 패키지를 설치할 필요가 없습니다. 브라우저가 저장소 루트의 `index.html`, `src/`, `styles/`, `assets/`를 그대로 읽습니다. 별도 번들과 백엔드는 없습니다. 브라우저는 `index.html`의 import map에 고정된 GameKit 모듈을 jsDelivr에서 읽으므로 처음 실행할 때 인터넷 연결이 필요합니다. ES 모듈이므로 파일을 더블클릭하는 대신 HTTP 서버로 여세요.

- **초기 로딩:** 진행률은 게임 모듈, 홈 이미지, 배경음 준비가 끝날 때 갱신됩니다. 로딩과 홈 화면에서 게임 버전을 확인할 수 있습니다.
- **홈 시연:** 화면 너비를 채우는 타이틀 장면에서 숲길 연쇄 타격, 대시와 공 회수, 폭풍 길 훅 투구가 3초씩 반복됩니다. 기기에서 동작 줄이기를 켜면 정지 그림을 표시합니다.
- **플레이 소개:** 홈에서 **소개 보기**를 누르거나 `#/showcase` 주소를 엽니다. 실제 경기 시연을 일시정지하거나 다시 볼 수 있고, **직접 플레이**는 게임 시작 화면을 엽니다. 소개는 무음이며 플레이 기록과 해금에 영향을 주지 않습니다.
- **캠페인:** **게임 시작 → 캠페인**에서 맵 카드를 고릅니다. 잠긴 맵은 해금 조건을 표시합니다.
- **1대1 대전:** **게임 시작 → 1대1 대전**에서 상대를 고릅니다. **친구와 대전**은 같은 버전을 쓰는 친구와 4자리 방 코드로 연결합니다. **AI 연습**은 로딩이 끝난 뒤 네트워크 연결 없이 바로 시작하며 같은 경기 규칙을 사용합니다.
- **대전 규칙:** 내 코트에서 공의 직격과 연쇄로 중립 핀 300개를 먼저 쓰러뜨리면 승리합니다. 같은 틱에 둘 다 달성하면 무승부입니다. 각 코트에 4초마다 일반 핀 15개와 특수 핀 1개가 나옵니다. 개인 6처치마다 상대 코트로 특수 핀 하나를 보내고, 다음 웨이브에서 예약된 핀이 도착하는 것을 볼 수 있습니다. 핀은 자기 코트의 오리를 노립니다.
- **이동:** 화면 왼쪽 방향 패드 또는 WASD. 입력을 누르고 있으면 준비된 대시가 이어집니다.
- **투구:** 오른쪽 패드에서 밀고 놓습니다. 끝을 휘면 훅. 키보드는 투구 영역을 선택하고 방향키로 각도·힘을 조정한 뒤 Space 또는 Enter를 누릅니다.
- **반사 바위:** 폭풍 협곡 입구의 바위는 공을 한 번 튕기고 깨집니다. 5초 뒤 오리·핀·공이 없는 다른 후보 위치에 무작위로 나타납니다. 조준선의 원은 반사 지점을 가리킵니다.
- **진행:** 구역을 정리하고 증강을 고른 다음 열린 입구를 넘습니다. 숲길에서 5구역에 도달하면 폭풍 길을 고를 수 있습니다.
- **메뉴:** 홈과 일시정지에서 설정에서 조작법과 기록을 보고 소리를 켜거나 끌 수 있습니다. 일시정지에서 이번 판을 끝내면 맵 선택으로 돌아갑니다. 해금한 맵의 결과에서는 바로 다시 굴릴 수 있습니다.
- **사운드:** 첫 클릭이나 키 입력부터 배경음이 재생됩니다. 도중에 설정에서 소리를 끌 수 있습니다. 배경음 출처는 [오디오 크레딧](assets/audio/CREDITS.md)에 있습니다.
- **저장:** 브라우저의 같은 출처에서 기록과 해금이 남습니다. 다른 호스트의 기록은 자동으로 옮겨지지 않습니다.

## 개발

로컬에서 추가 확인이 필요할 때는 아래 명령을 실행합니다.

```sh
npm ci
npm run check
npm test
```

`npm run check`는 콘텐츠 목록·포맷·린트, `npm test`는 숲길·폭풍 길 완주 시나리오를 로컬에서 실행합니다. PR CI는 변경된 JavaScript(`.js`, `.mjs`, `.cjs`)의 문법과 콘텐츠 목록 일치 여부를 확인하고, 패키지 설치·포맷·린트·테스트는 실행하지 않습니다. 책임 배치는 [구조 문서](docs/architecture.md), Build 57 출처와 검증 범위는 [이관 기록](docs/migration.md), 공통 규칙 링크는 [작업 안내](AGENTS.md)에 있습니다.

맵이나 플레이어 캐릭터를 추가하는 방법은 [콘텐츠 정의](docs/architecture.md#콘텐츠-정의)에 있습니다.
